# PureData-Sequencer
A Beat Sequencer and Sampler made in PureData!
This project has 4 parts: the main sequencer, an audio sampler, the drum set, and a visualization tool.
The main sequencer is an 8 beat cycle and its speed can be adjusted.  It can also algorithmically generate a beat sequence for the drumset.
The sampler takes in an audio file, and the user can select which sections they want to chop. They can adjust the pitch, volume, and speed of the selected sample.
The snare, kick, and hi-hat are created by manipulating audio signals into the right sound.
The visualization tool was made using the Graphics Environment for Multimedia (GEM) library.
